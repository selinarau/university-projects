# University projects

I graduated in December 2025 from Mathematics of Computing Master's program of Tampere University, Finland.
My Master's degree included 80 credits of mathematics and 76 credits of computer science studies. 
Before that I have completed a Bachelor degree from Mathematics and during that I focused also computer science and statistics.

This repository is for my university projects and exercises. Some of them are in Finnish and some in English, some I have translated.
Projects are written in different programming languages, there are exercises in python, java, C, PHP, node.js and so on. 

Shortly about the projects:
* **Algorithms and Data Structures** contains exercises of different algorithms of sorting, text correction and graphs and queues. 
* **Database Fundamentals** shows basic understanding of relations and SQL. 
* **Database Programming** includes a project of a bookshop and it focuses more how databases can be accessed and used.
* **Recommender Systems** project is a Jupyter Notebook, where I have created algorithms to recommend movies based on their ratings. There are also some pdf presentations I did for the course to explain the choices I have done.
* **Software Design** project is a route planner web application that is unfortunately unfinished. I added it anyway here, because I think there might be something interesting to see and who knows maybe I get motivation to finish it one day.
* I also included essays of the **Information Systems and Society** course, even if they are in Finnish (if someone is curious enough, translate with AI) to demonstrate my capability of ethical and critical thinking and writing.

Database programming and Software Design projects were group work but the rest I have done individually.
